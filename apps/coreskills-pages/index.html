The problem

Capabilities deserve better than copy-paste folklore.

Skills usually arrive as prose in a chat, a gist, or a screenshot. CoreSkills gives them a durable shape, a verifiable identity and a history you can actually reason about.

✎

Ambiguous format

A skill is prose, metadata and permission requests mixed together. Without a contract, two “identical” copies are not identical.

◈

Vague permissions

“Needs file access” tells you nothing. CoreSkills records exact scopes so a human can decide what to allow.

⟲

Lost provenance

Editing in place erases where a skill came from. Every version stays content-addressed and restorable.

What you get

A workshop, not a black box.

Everything is inspectable. The catalog is a local library with a paper trail.

✦

Live authoring

Write SKILL.md in CodeMirror with validation as you type. Errors are clear; warnings stay visible.

⇩

Guarded import

Paste or pick files. Stable codes such as FM001 and SEC001 tell you exactly what happened.

⧉

Immutable versions

Edits create new hash-addressed versions. Restore any earlier state without destroying the present.

⌕

Fast discovery

Search by name, description or tag; filter by capability kind; sort by recency or name.

Portable bundles

How it works

From raw text to trusted capability.

Six small steps, each observable. Nothing is accepted silently.

Parse

Diagnose

Conformance rules emit errors, warnings and notes.

Review

You decide what enters the catalog. Errors always block.

Version

Canonical bytes are hashed and stored immutably.

Share

Export a single file or a verified portable bundle.

Strategic fit

CoreSkills defines what. CoreBase decides how.

CoreSkills produces portable capability descriptions with explicit scopes. CoreBase consumes them as intents, plans execution, asks for approval and records the result in a hash-chained audit.

  • Shared contracts mean a skill written here is intelligible there.
  • Permissions are data, not vibes — so agents can request and humans can revoke.
  • Identity is content-addressed, so provenance survives export and import.

Quick start

Open the app, choose Author, and start from a sample. Validation runs live. When the document is clean, save it to the local catalog. No account screen exists — guest mode is the product.

PWA-ready: install from your browser’s menu for an offline-capable app shell. All skill bytes stay in IndexedDB on that device.

SKILL.md shape

A document is YAML frontmatter plus a Markdown body. The canonical form sorts tags, normalises line endings and hashes the result.

example SKILL.md
---
name: meeting-notes
description: Turn notes into decisions and owners.
version: 0.2.0
tags: [meetings, writing]
kind: human-skill
permissions:
  - scope: workspace.files.read
    reason: Read the supplied notes
---

Summarise decisions, owners and open questions.
Never invent an owner.

Diagnostics

Codes are stable so tooling and humans can reason about them. Errors block import; warnings and notes are surfaced for review.

CodeLevelMeaning
FM001ErrorMissing YAML frontmatter block.
SEC001WarningBody contains instruction-override language.
ID001NoteIdentity derived from canonical content, not filename.

Permissions

Each request names a scope, a reason and an expected effect. CoreSkills never executes a skill; it describes authority so an executor can ask precisely.

Read this before trusting a skill. A checksum proves that bytes match a known identity. It does not prove the bytes are benign. Review the body and the permission scopes yourself.

Storage & bundles

The browser stores skills, versions, settings and import reviews in IndexedDB. A portable bundle uses oneorigin.bundle/v0.0.1 and carries current documents plus their history. Every item hash and the bundle manifest are verified before import writes anything.

Questions

Honest answers.

Do I need an account?

No. Guest mode is the default and the complete experience. There is no sign-in, no sync service and no telemetry toggle to find.

Does a verified bundle mean a skill is safe?

No. Verification establishes integrity and origin — that the bytes match the recorded identity. Safety still requires human review of the body and requested scopes.

Can CoreSkills run my skills?

No. It is a catalog and authoring tool. Execution belongs to CoreBase, which plans actions and asks for explicit approval before touching a virtual workspace.

What happens if I edit a skill?

A new immutable version is written. The previous version remains restorable, and the identity changes because identity is derived from canonical content.
